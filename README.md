# CodeOrbit Tech - To-Do List CLI App

## Project Description
The To-Do List CLI App is a Python command-line application that helps users organize their daily tasks. Users can add, view, and remove tasks.

## Features
- Add new tasks
- View all tasks with numbers
- Remove tasks by number
- Save tasks to a text file
- Load saved tasks when the program restarts
- Handle invalid menu choices and task numbers

## Technologies Used
- Python 3
- Visual Studio Code
- File handling

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

```bash
python todo_list.py
```

## Files
- `todo_list.py` - Main Python program
- `README.md` - Project documentation
- `tasks.txt` - Created automatically to store tasks

## Learning Outcomes
This project demonstrates Python lists, functions, loops, conditional statements, exception handling, and file handling.
